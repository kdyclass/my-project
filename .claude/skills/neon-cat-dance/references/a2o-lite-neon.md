# A2O LITE 'NEON' 프리셋

2026-10-15 검색 기준. 모델이 이 곡을 모를 수 있으니, 여기 적힌 것과 사용자가 준 영상만 근거로 쓴다.

## 확인된 사실

- 그룹: A2O LITE(에이투오 라이트). 이수만 대표의 A2O 엔터테인먼트 소속 9인조. 평균 나이 15세 안팎이고, 2013년생 멤버가 3명이다.
- 곡: 'NEON'. 2026-10-13 발매한 데뷔 디지털 싱글이고, 발매 29시간 만에 멜론 TOP100 1위에 올랐다.
- 화제가 된 퍼포먼스: 곡 도입부의 2인 인트로 안무(시리, 아이찡). 킬링 파트는 아이찡의 한 발 턴이고, 보아를 떠올리게 한다는 반응이 많았다. 안무는 J-Black(제이블랙)이 만들었고 크림 댄스의 이동규, 최인영이 함께했다.
- 밈: 후렴 'Neon and Beyond'가 '미혼앤비혼'으로 들린다는 몬더그린.
- 뮤비: 4DGS(4D 가우시안 스플래팅)로 여러 각도에서 볼 수 있게 찍었다.

## 확인 못 한 것 (사용자에게 받는다)

- 뮤비의 실제 색감. 기본값은 핫핑크 `#FF2EC4`와 일렉트릭 블루 `#2E9BFF`로 둔다(`finish_vertical.sh` 자막 색과 같다).
- 정확한 안무 카운트.
- 레퍼런스 영상 안에서 후렴과 한 발 턴이 나오는 시점.

## 레퍼런스를 쓰는 원칙

- 멤버 대부분이 미성년자다. 동작만 빌리고, 얼굴과 의상, 이름이 결과물에 남지 않게 한다. 결과 프레임에 사람 흔적이 보이면 그 결과는 버린다.
- 2인 안무라서 솔로 영상을 만들 때는 한 발 턴을 하는 멤버 쪽만 `prep_reference.sh -c` 로 잘라 쓴다. 같은 반려동물 두 마리로 듀오를 만들고 싶으면 사람마다 따로 생성한 뒤 좌우로 붙인다.
